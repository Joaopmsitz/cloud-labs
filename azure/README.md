## Areas of Practice

- Microsoft Sentinel and Log Analytics.
- Security data ingestion and monitoring.
- KQL queries and threat hunting.
- Analytics rules and incident investigation.
- Microsoft Defender XDR and Advanced Hunting.
- SIEM/SOAR concepts and security automation.
- Azure security and network monitoring.

## Security and Responsible Use

- Use authorized lab environments.
- Never publish credentials, access tokens, account identifiers, or sensitive information.
- Sanitize screenshots and logs before publication.
- Preserve attribution for third-party materials.
- Review the licensing and redistribution restrictions of training materials before publishing.
