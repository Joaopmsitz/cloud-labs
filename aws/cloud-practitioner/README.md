# AWS Cloud Practitioner — Labs

> AWS Certified Cloud Practitioner preparation

This learning path contains foundational AWS labs and practical activities that reinforce knowledge of cloud concepts, AWS services, security, networking, and infrastructure.

The activities are supplementary practical exercises and do not represent complete coverage of the certification exam objectives.

## Labs

| Lab | Description | Status |
|---|---|---|
| [01 — Introduction to Amazon VPC](./labs/01-introduction-to-amazon-vpc/README.md) | Explore Amazon VPC, public and private subnets, Internet Gateway, NAT Gateway, route tables, Network ACLs, and Security Groups. | Not started |

## Study Focus

- Cloud concepts and AWS global infrastructure.
- Core AWS services.
- Identity and access management.
- Networking fundamentals.
- Security and shared responsibility.
- Cost management and support concepts.

## Documentation Guidelines

Each lab should include:

- Objectives and architecture.
- Implementation steps written in your own words.
- Original screenshots or diagrams.
- Technical observations and validation.
- Lessons learned.
- Resource cleanup and cost considerations.
